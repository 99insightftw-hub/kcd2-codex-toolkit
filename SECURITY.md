# Security and responsible use

Do not submit game binaries, proprietary assets, extracted archives, IDA/Ghidra databases, unrestricted decompilation, personal saves, private indexes, credentials, or machine-specific analyst metadata.

Native tooling is intended for lawful interoperability and research against software you own. Passive observation is the default. Runtime writes, patching, process control, installation, and shared-state mutation require separate explicit safeguards outside the research skill.

Please report a security issue privately through GitHub's security advisory feature rather than opening a public issue containing sensitive data.
